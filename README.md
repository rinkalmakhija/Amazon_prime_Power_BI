# Amazon Prime Video Data Analysis Dashboard

An interactive Power BI dashboard analyzing content distribution, ratings, runtime, and audience demographics for Amazon Prime Video.


---

## 📌 Project Overview
This project provides an end-to-end exploratory analysis of Amazon Prime Video's content catalog. The dashboard offers key data-driven insights into release trends, genre popularity, ratings distributions, and movie-to-show ratios.

---

## 📊 Key Metrics & Highlights
* **Total Titles:** 8,746
* **Average IMDb Score:** 5.97 / 10
* **Average Runtime:** 95.58 minutes
* **Total Customers Reach:** ~8,861K

---

## 💡 Key Visualizations & Insights

* **Content Type Breakdown:** Donut chart showcasing the proportional split between **Movies vs. TV Shows**.
* **Release Trends Over Time:** Line chart displaying title growth from **1912 to 2022**, highlighting the modern streaming boom.
* **Ratings & Ratings Certification:** Bar chart categorizing titles by maturity rating (`R`, `PG-13`, `TV-MA`, `PG`, `G`, etc.).
* **Genre Distribution:** Analysis of content spread across major genres (`Drama`, `Comedy`, `Documentary`, `Thriller`, etc.).
* **Runtime vs. IMDb Rating Analysis:** Scatter plot illustrating the correlation between content length and viewer ratings.

---

## 🛠 Tools & Technologies
* **Business Intelligence:** Power BI Desktop
* **Data Sources:** Amazon Prime Video Catalog Dataset
* **Visualizations:** KPI Cards, Donut Charts, Line Charts, Bar Charts, Scatter Plots, Interactive Slicers
